Step 33 · Tệp CSV

Bảng điểm cả lớp

Mỗi dòng là một hàng, các cột cách nhau bởi dấu phẩy. Chú ý: số đọc từ CSV vẫn là xâu.

import csv
with open("diem.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows([["ten", "diem"], ["An", 8], ["Bình", 6.5], ["Chi", 9]])
with open("diem.csv", encoding="utf-8") as f:
    for hang in csv.DictReader(f):
        print(hang["ten"], float(hang["diem"]) + 0.5)

Step 35 · Dự án nhỏ

Báo cáo điểm từ CSV

Ghép mọi thứ đã học: đọc dữ liệu, tính toán, lọc, rồi in báo cáo.

import csv, io
dl = "ten,toan,van\nAn,8,7\nBình,5,6\nChi,9,9.5\n"
hs = list(csv.DictReader(io.StringIO(dl)))
for h in hs:
    h["tb"] = (float(h["toan"]) + float(h["van"])) / 2
hs.sort(key=lambda h: h["tb"], reverse=True)
for h in hs:
    print(f"{h['ten']:<6}{h['tb']:5.2f}")
print("Giỏi:", [h["ten"] for h in hs if h["tb"] >= 8])

Step 36 · Lớp và đối tượng

Mô hình hoá học sinh

class là bản thiết kế, còn object là một bạn cụ thể. self chính là object đó.

class HocSinh:
    def __init__(self, ten, diem):
        self.ten = ten
        self.diem = diem
    def tb(self):
        return sum(self.diem) / len(self.diem)

an = HocSinh("An", [8, 9, 7])
print(an.ten, round(an.tb(), 2))
an.diem.append(10)
print(round(an.tb(), 2))
