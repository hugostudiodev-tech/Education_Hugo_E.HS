Step 29 · Module và import

Dùng code của người khác

import x, from x import y, import x as z. Python có sẵn rất nhiều module.

from math import sqrt
import statistics as st
import datetime
diem = [7, 9, 6.5, 8]
print(sqrt(2))
print(st.mean(diem), st.median(diem))
print(datetime.date.today())

Step 30 · Dự án nhỏ

Thư viện tính điểm

Gom các hàm dùng nhiều lần thành một bộ để dùng lại.

def trung_binh(ds): return sum(ds) / len(ds)
def xep_loai(tb): return "Giỏi" if tb >= 8 else "Khá" if tb >= 6.5 else "TB" if tb >= 5 else "Yếu"

lop = {"An": [8, 9], "Bình": [6, 7], "Chi": [4, 5.5]}
for ten, ds in lop.items():
    tb = trung_binh(ds)
    print(f"{ten:<6}{tb:5.2f}  {xep_loai(tb)}")

Step 31 · try và except

Chương trình không sập

Đặt đoạn có thể lỗi vào try, rồi bắt đúng loại lỗi trong except.

while True:
    try:
        d = float(input("Điểm: "))
        break
    except ValueError:
        print("Phải nhập số, thử lại!")
print("OK:", d)

Nhập chữ tám thì lỗi gì?

ValueError, vì float() không đổi được chữ thành số.

Step 32 · Đọc và ghi tệp

Lưu lại cho lần sau

"w" ghi mới (xoá nội dung cũ), "a" ghi nối thêm, "r" để đọc. Nên dùng with để tệp tự đóng.

with open("lop.txt", "w", encoding="utf-8") as f:
    f.write("An\nBình\n")
with open("lop.txt", "a", encoding="utf-8") as f:
    f.write("Chi\n")
with open("lop.txt", encoding="utf-8") as f:
    for dong in f:
        print(dong.strip())

Thử thách · 5 phút

Máy tính an toàn

Nhập a và b rồi in a / b. Bắt cả hai lỗi ValueError và ZeroDivisionError. Bạn nào xong trước thì dán code vào chat, mình chạy cho cả lớp xem.

try:
    a = float(input("a = "))
    b = float(input("b = "))
    print(a / b)
# except ...

Lỗi hay gặp

Vì sao mất dữ liệu?

Bấm Chạy, đọc dòng lỗi cuối cùng, sửa từng lỗi rồi chạy lại.

with open("nhatky.txt", "w") as f:
    f.write("Ngày 1\n")
with open("nhatky.txt", "w") as f:
    f.write("Ngày 2\n")
print(open("nhatky.txt").read())
try:
    x = 1 / 0
except:
    pass

Chế độ "w" xoá sạch tệp cũ, muốn ghi thêm thì dùng "a". Còn except: pass nuốt mất mọi lỗi nên không biết sai ở đâu.
