Step 37 · random

Trò chơi đố vui ôn bài

random.choice, random.randint, random.shuffle. Lưu ý: shuffle xáo trộn ngay trên list và trả về None.

import random
cau_hoi = {"2 ** 5": "32", "17 % 5": "2", "len('Hugo')": "4"}
ds = list(cau_hoi)
random.shuffle(ds)
for q in ds[:2]:
    tl = input(f"{q} = ")
    print("Đúng!" if tl == cau_hoi[q] else f"Sai, đáp án {cau_hoi[q]}")

Step 38 · Tìm kiếm và sắp xếp

Tìm nhị phân

Trên list đã sắp xếp, mỗi lần đoán loại được một nửa số ứng viên. Với 1–100, tối đa 7 lần là tìm ra.

ds = list(range(1, 101))
muc_tieu = 73
trai, phai, lan = 0, len(ds) - 1, 0
while trai <= phai:
    giua = (trai + phai) // 2
    lan += 1
    print(f"Lần {lan}: đoán {ds[giua]}")
    if ds[giua] == muc_tieu: break
    if ds[giua] < muc_tieu: trai = giua + 1
    else: phai = giua - 1

Tìm 1 triệu số thì cần tối đa bao nhiêu lần?

Khoảng 20 lần, vì 2 mũ 20 ≈ 1 triệu.

Step 39 · Đệ quy

Hàm tự gọi chính nó

Hàm đệ quy cần có trường hợp cơ sở để dừng lại, nếu không sẽ gặp lỗi RecursionError.

def giai_thua(n):
    if n <= 1:
        return 1
    return n * giai_thua(n - 1)

for i in range(1, 8):
    print(i, giai_thua(i))

Bỏ dòng if n <= 1 thì sao?

Hàm gọi mãi không dừng và gặp lỗi RecursionError.

Step 40 · Cài Python và dự án tốt nghiệp

Sổ Lớp

Cài Python từ python.org (nhớ tích Add to PATH) và dùng VS Code. Dự án Sổ Lớp ghép mọi thứ đã học.

class SoLop:
    def __init__(self):
        self.hs = {}
    def them(self, ten, *diem):
        self.hs[ten] = list(diem)
    def bao_cao(self):
        for ten, ds in sorted(self.hs.items()):
            tb = sum(ds) / len(ds)
            print(f"{ten:<6}{tb:5.2f}")

s = SoLop()
s.them("An", 8, 9)
s.them("Bình", 6, 7.5)
s.bao_cao()

Nâng cấp Sổ Lớp

Thêm phương thức top(k) trả về k bạn có điểm trung bình cao nhất. Bạn nào xong trước thì dán code vào chat, mình chạy cho cả lớp xem.

class SoLop:
    def __init__(self):
        self.hs = {}
    def them(self, ten, *diem):
        self.hs[ten] = list(diem)
    # def top(self, k): ...

s = SoLop()
s.them("An", 8, 9); s.them("Bình", 6, 7); s.them("Chi", 9, 10)
print(s.top(2))

Bấm Chạy, đọc dòng lỗi cuối cùng, sửa từng lỗi rồi chạy lại.

import random
ds = [1, 2, 3]
ds = random.shuffle(ds)
print(ds)
def dem(n):
    print(n)
    dem(n - 1)
dem(3)

1. shuffle trả về None, chỉ cần viết random.shuffle(ds). 2. Hàm đệ quy thiếu điều kiện dừng: thêm if n == 0: return.
