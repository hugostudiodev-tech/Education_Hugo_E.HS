Step 25 · tuple, set và sổ quỹ lớp

Bộ không đổi và tập không trùng

tuple không sửa được. set tự loại bỏ phần tử trùng.

thu = [("An", 20), ("Bình", 20), ("An", 10)]
nguoi = set()
tong = 0
for ten, tien in thu:
    nguoi.add(ten)
    tong += tien
print("Đã đóng:", sorted(nguoi))
print("Quỹ:", tong, "nghìn")

Có mấy bạn đã đóng quỹ?

2 bạn, vì set loại bỏ tên An bị trùng.

Step 26 · def và return

Hàm đầu tiên

Hàm nhận đầu vào, xử lý rồi return kết quả. Lệnh print chỉ hiện ra màn hình, không trả lại giá trị nào.

def trung_binh(a, b, c):
    return (a + b + c) / 3

x = trung_binh(7, 8, 9)
print(x)
print(trung_binh(5, 5, 6) >= 5)

Step 27 · Tham số và phạm vi

Giá trị mặc định và biến cục bộ

Biến tạo bên trong hàm chỉ tồn tại trong hàm đó.

def chao(ten, loi="Xin chào"):
    cau = f"{loi}, {ten}!"
    return cau

print(chao("Lan"))
print(chao("Minh", "Hello"))
print(cau)

Dòng cuối sẽ thế nào?

NameError, vì cau là biến cục bộ, ra ngoài hàm thì không còn.

Step 28 · Chia nhỏ bài toán

Hàm gọi hàm và docstring

Mỗi hàm chỉ làm một việc. Docstring là dòng mô tả ngay dưới def.

def xep_loai(tb):
    """Trả về học lực theo điểm trung bình."""
    if tb >= 8: return "Giỏi"
    if tb >= 6.5: return "Khá"
    return "TB" if tb >= 5 else "Yếu"

def bao_cao(ten, ds):
    tb = sum(ds) / len(ds)
    return f"{ten}: {tb:.1f} ({xep_loai(tb)})"

print(bao_cao("An", [8, 9, 7.5]))

def la_nguyen_to(n):
    # n < 2 thì False; thử chia cho 2..n-1
    pass

for i in range(30):
    if la_nguyen_to(i):
        print(i, end=" ")

Lỗi hay gặp

Vì sao in ra None?

Bấm Chạy, đọc dòng lỗi cuối cùng, sửa từng lỗi rồi chạy lại.

def tong(a, b):
    print(a + b)

x = tong(2, 3)
print(x * 2)

Hàm chỉ print chứ không return, nên x là None và None * 2 bị lỗi TypeError. Sửa thành return a + b.
