Step 5 · Đọc thông báo lỗi

Lỗi là lời nhắn của Python

Đọc từ dưới lên. Dòng cuối cho biết loại lỗi, dòng line … cho biết lỗi nằm ở đâu.

diem = 9
print("Điểm:", Diem)

Đây là loại lỗi gì?

NameError: Python phân biệt chữ hoa và chữ thường, nên Diem khác diem.

Step 6 · Toán tử số học

Chia nguyên, chia lấy dư, luỹ thừa

/ luôn ra số thực, // lấy phần nguyên, % lấy số dư, ** là luỹ thừa.

print(17 / 5)
print(17 // 5)
print(17 % 5)
print(2 ** 10)
phut = 135
print(phut // 60, "giờ", phut % 60, "phút")

135 phút là mấy giờ mấy phút?

2 giờ 15 phút: 135 // 60 = 2 và 135 % 60 = 15.

Step 7 · Thứ tự ưu tiên và làm tròn

Máy tính cũng tính sai… một chút

Thứ tự: ** rồi đến * / // % rồi đến + -. Số thực có sai số rất nhỏ, nên hãy dùng round().

print(2 + 3 * 4 ** 2)
print((2 + 3) * 4)
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(round(0.1 + 0.2, 2))

0.1 + 0.2 có bằng 0.3 không?

Không. Máy lưu số thực ở hệ nhị phân nên ra 0.30000000000000004. Vì vậy khi so sánh nên làm tròn trước.

Step 8 · f-string

In kết quả cho đẹp

Thêm chữ f trước dấu ngoặc kép rồi đặt biến trong {}. Viết {x:.2f} để lấy 2 chữ số thập phân.

ten = "Lan"
tb = 8.3333
print(f"Bạn {ten} được {tb:.2f} điểm")
print(f"{ten:>6}|{tb:6.1f}|")

Thử thách · 5 phút

Đổi giây ra giờ:phút:giây

Nhập một số giây và in ra dạng 1:02:05. Bạn nào xong trước thì dán code vào chat, mình chạy cho cả lớp xem.

s = int(input("Số giây: "))
gio = s // 3600
# phut = ?
# giay = ?
print(f"{gio}:{phut:02}:{giay:02}")

Lỗi hay gặp

Tìm 2 lỗi

Bấm Chạy, đọc dòng lỗi cuối cùng, sửa từng lỗi rồi chạy lại.

a = int(input("a = "))
b = int(input("b = "))
print("Trung bình: {(a + b) / 2}")
print("Tổng", a + b

1. Thiếu chữ f trước xâu nên {…} bị in nguyên văn. 2. Thiếu dấu ) ở dòng cuối.
