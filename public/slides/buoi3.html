Step 9 · Module math

Mượn đồ nghề có sẵn

import math rồi dùng math.sqrt, math.ceil (làm tròn lên), math.floor (làm tròn xuống), math.pi.

import math
print(math.sqrt(16))
print(math.ceil(4.1))
print(math.floor(4.9))
hs = 43
print("Cần", math.ceil(hs / 4), "xe 4 chỗ")

43 bạn đi xe 4 chỗ thì cần mấy xe?

11 xe. Ra 10.75 thì vẫn phải thuê thêm xe, nên dùng ceil để làm tròn lên.

Step 10 · Dự án nhỏ

Điểm trung bình môn theo hệ số

Điểm thường xuyên hệ số 1, giữa kỳ hệ số 2, cuối kỳ hệ số 3.

tx = float(input("Thường xuyên: "))
gk = float(input("Giữa kỳ: "))
ck = float(input("Cuối kỳ: "))
tb = (tx + gk * 2 + ck * 3) / 6
print(f"Điểm trung bình: {tb:.1f}")

Step 11 · So sánh và bool

Câu hỏi có/không

== != < > <= >= đều trả về True hoặc False. Chú ý: = là gán, == là so sánh.

print(8 >= 6.5)
print("lan" == "Lan")
diem = 5
print(diem != 5)
print(3 < diem <= 10)

"lan" == "Lan" ra gì?

False, vì chữ hoa và chữ thường là khác nhau.

Step 12 · if và else

Hai ngả đường

Sau if và else phải có dấu :. Các dòng bên trong thụt vào 4 dấu cách.

diem = float(input("Điểm: "))
if diem >= 5:
    print("Đạt")
    print("Chúc mừng!")
else:
    print("Chưa đạt")
print("Hết")

Nhập 4.5 thì in ra mấy dòng?

Hai dòng: Chưa đạt và Hết. Dòng Hết không thụt vào nên luôn chạy.

Lỗi hay gặp

Tìm 3 lỗi

Bấm Chạy, đọc dòng lỗi cuối cùng, sửa từng lỗi rồi chạy lại.

diem = input("Điểm: ")
if diem = 10
    print("Tuyệt đối!")

1. Phải đổi kiểu: float(input(...)). 2. So sánh dùng ==. 3. Thiếu dấu : sau điều kiện.
